## The Most Persuasive Kind of Evidence

Class guides run on claims; this one gets to run on footage. The Bard's Season 10 case rests on a documented run of all nine [act bosses](/bosses/hero-siege-act-bosses-guide/) cleared on **Inferno** — the top of the [difficulty ladder](/guides/hero-siege-difficulty-guide/) — by a community creator whose run is embedded below. Whatever else a class guide argues, a hardest-difficulty full-act clear is the kind of evidence that ends arguments.

<Callout type="info" title="What the run proves — and what it does not">
One documented Inferno act clear proves the class's ceiling: it can be done, on film, in this season. It does not prove the Bard is the strongest class, the easiest class, or that every Bard build replicates the run. Treat it as existence proof — the strongest kind for a class's viability case, the wrong kind for a guarantee.
</Callout>

## Reading the Inferno Run as a Player

The run is worth studying rather than just citing, because it demonstrates the transferable parts of the class's endgame case:

- **Act bosses at the top ladder are a kit exam.** Nine bosses in one Inferno pass means nine different pattern checks survived back-to-back — the clearest demonstration possible that the build's damage and survivability plans are both real.
- **Sustain and positioning carried it.** Watch how the run handles the fights that punish contact and greed — the lessons transfer to every [endgame exam](/bosses/hero-siege-uber-bosses-guide/), including the [S10 Uber layer](/bosses/hero-siege-uber-bosses-guide/).
- **The build was completed first.** No class clears Inferno acts on transition gear; the run is also a demonstration of the [endgame gear arc](/items/hero-siege-uniques-overview/) finished properly.

## How a Bard Season Reaches That Ceiling

The run's route is the game's standard endgame arc, played with discipline:

1. **Campaign and levels** — the [standard route](/guides/hero-siege-beginner-guide/), spending skill points into one kit instead of five.
2. **The [difficulty ladder](/guides/hero-siege-difficulty-guide/)** — where the build's damage plan either proves out or gets fixed. The class's range and rhythm earn their keep as content starts punishing melee greed.
3. **The endgame economy** — [wormhole](/guides/hero-siege-wormhole-guide/) volume, [Uber](/bosses/hero-siege-uber-bosses-guide/) rotations, the [market](/guides/hero-siege-market-guide/) and [gold income](/guides/hero-siege-gold-farming-guide/) that fill [gear slots](/items/hero-siege-viking-bis/) on schedule.
4. **The Inferno act pass itself** — the run documented above, replicable on a completed build with honest execution.

## Bard FAQ

### Bard or a safer pick for a second character?

If the playstyle description appeals, the class is a legitimate pick — its endgame evidence is stronger than most. If you want the community's deepest documentation while the Bard's written guides settle, the [Viking](/guides/hero-siege-viking-build/) and [Marksman](/guides/hero-siege-marksman-build/) pages carry the largest proven repositories.

### Does the Inferno act run mean Bard clears the Uber layer too?

One feat does not transfer automatically — the [Uber roster](/bosses/hero-siege-uber-bosses-guide/) is a different exam above the act content. What transfers is the completed build and the execution habits; the Uber layer's documentation is its own chapter.

### Where does the Bard sit on the Season 10 tier list?

Tier-list position is community consensus and it moves with patch tuning — check the [current season list](/guides/hero-siege-class-tier-list/) for the live ranking. This page documents what the class has verifiably done; the list documents what players currently believe.
