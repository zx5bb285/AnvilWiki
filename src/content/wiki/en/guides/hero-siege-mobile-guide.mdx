## One ARPG, Three Homes

Hero Siege is older than its Steam success — the game's mobile version has existed for years, per the developer's own platform description, and PlayStation 5 joined the roster in Season 9. For a player deciding where to play in the [current season](/guides/hero-siege-season-10-guide/), the honest answer has three parts: what each platform verifiably offers, what remains unconfirmed, and what the community's documentation actually covers.

<Callout type="info" title="Verified vs unconfirmed, stated plainly">
Platform facts on this page come from the official game description and season announcements. Crossplay state, controller support details and per-platform pricing are NOT verified here — this page marks them as open questions rather than inventing answers, and the official store pages are the source of truth.
</Callout>

## The Platforms, One by One

### Steam — the primary home

Steam (where the game has lived longest) is the platform the entire ecosystem assumes: creator guides, build videos, community tools and this site's guides all document the PC version first. Console-style features — [hardcore mode](/guides/hero-siege-hardcore-and-coop-guide/), multiplayer, seasonal leagues — are documented in PC terms. For a new player who wants the smoothest information trail, Steam is the default answer.

### PlayStation 5 — the console door

PS5 joined in Season 9, per the season's launch announcements, bringing the game to console players with the season model intact. Console-specific details — controller layouts, performance profiles, ecosystem features — are documented thinly compared to PC; console players should expect to lean on PC-oriented guides for build content, since the underlying game systems are the same.

### Mobile — the long-running pocket version

The mobile version predates the game's recent seasons, which makes it one of the more interesting platform stories in indie ARPGs: a full loot-game running on phones. What the mobile version's current feature set includes — how it tracks the PC version's seasons and systems like the [Ether Tree](/guides/hero-siege-ether-tree-guide/) — is not officially documented in detail, and this page will not guess. Players curious about the mobile experience should check the official store listing for current feature state.

## What to Expect Playing Away From a Desk

The honest framing of Hero Siege's portability: the game's core loops — [campaign acts](/bosses/hero-siege-act-bosses-guide/), [farming](/guides/hero-siege-gold-farming-guide/), [market](/guides/hero-siege-market-guide/) sessions — are session-sized by design, which suits short-form play. The systems that reward long sessions ([deep wormholes](/guides/hero-siege-wormhole-guide/), [Uber rotations](/bosses/hero-siege-uber-bosses-guide/), long [leveling](/guides/hero-siege-leveling-guide/) pushes) are where any non-desktop setup feels the difference.

Whatever the platform, the [beginner guide](/guides/hero-siege-beginner-guide/) and the [class roster](/guides/hero-siege-classes-list/) apply equally — the game systems do not change between screens, only the input and the information ecosystem around them.

## Platform FAQ

### Does progress sync between platforms?

Cross-platform progression is an open question on this page by design — no official documentation we can cite answers it, and a wrong answer costs players real progress assumptions. Check the official support channels before planning around it.

### Is the mobile version the full game?

Feature-parity details between mobile and desktop are not officially documented. The safe assumption for planning purposes: treat the PC version as the reference experience and verify any specific system on the mobile store listing.

### Where do platform announcements appear?

The developer's news section and the official social channels carry platform news — the same sources as the [patch tracker](/guides/hero-siege-patch-notes/). Platform changes tend to arrive alongside season announcements.
