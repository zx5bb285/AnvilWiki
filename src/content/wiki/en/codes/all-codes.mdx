## How to Redeem Codes in Hero Siege

Redemption works differently from most games — there is no settings menu:

1. **Open the in-game chat.**
2. **Type `#`.** A redeem window pops up.
3. **Enter the code** exactly as published (codes are case-sensitive as far as community testing shows).

That is the official flow straight from the developer's own code announcements — most "Hero Siege code" articles on aggregators never explain it correctly.

## Where New Codes Actually Appear

In order of reliability:

1. **The official Discord server** — the developer's primary community channel and the fastest source for any code drop.
2. **The official Facebook page** — where past codes like HHEBGIFT were published.
3. **The developer's X/Twitter account** — occasional promotions.
4. **Season launch events** — while Hero Siege does not do monthly codes, launches and milestones are the occasions when codes historically appear.

If you see a code claimed elsewhere, the test is always the same: does an official-channel post exist for it? If not, assume expired or fabricated.

## A Note on "Code Sites"

Hero Siege codes have an unusual secondary use documented in community discussions: the developer has historically used the code system to help players **recover single-player characters lost to bugs**, rather than only for promotions. This is why some players report receiving "codes" from support. It also means most content-farm code pages — which recycle a handful of 2023-era strings into "Active codes" lists updated by template — have never been accurate about this game.

Our policy for this page, and for every [guide](/guides/hero-siege-beginner-guide/) on this site: list only codes with a verifiable official source, mark expiry honestly, and say plainly when nothing is active.

While you are here: codes are a nice-to-have, not a progression system — the real power curve this season runs through the [Ether Tree](/guides/hero-siege-ether-tree-guide/) and the [Season 10 changes](/guides/hero-siege-season-10-guide/).

## FAQ

**Do codes expire?**
Yes — promotional codes are typically limited-time, and the developer does not always announce expiry dates in advance. HHEBGIFT is long past its window.

**Do codes work on all platforms?**
Historically, codes have been a PC-era system; console and mobile redemption may differ or be unavailable. Test in-game and treat platform claims as unverified until confirmed.

**I typed # and nothing happened. What now?**
Make sure you are in a game session (not the main menu) and using the chat input rather than another text field. If the window still does not appear, the feature may be unavailable on your platform build.

**Will there be codes for Season 10?**
No Season 10 codes have been announced as of mid-September 2026. Watch the official Discord around season milestones — this page tracks any that appear.
